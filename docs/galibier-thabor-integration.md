# Galibier-Thabor integration

User-selected fourth ski domain; Tignes is deferred. Galibier-Thabor links Valloire and Valmeinier. First candidate sector is Valloire village, Crêt de la Brive and the lower Sétaz vicinity; bbox W/S/E/N 6.426,45.145,6.473,45.174, origin 6.4495,45.1595. Approximate 3.7 x 3.2 km, not the whole domain. Actual route completeness depends on downloaded OSM and IGN validation; no claim that the full Sétaz or Valmeinier sectors are present. Sources: https://www.valmeinier.com/decouvrir/un-domaine-skiable-fantastique/ ; https://www.valloire.com/plan-des-pistes.html ; https://www.openstreetmap.org/node/616426563 ; https://www.openstreetmap.org/node/11117471936 (information point near the upper Brive station). The bbox is a project design choice. Wet-snow threshold 1500 m is visual tuning, not measured conditions.

New v2 resort IGN integration downloads real OSM, cross-checks the three IGN 5/20/60 m output grids, and archives geographic inputs before building. It uses the previously verified v2.0 compiler at 4dbbcd12be11f724d641d925b6df224895784d99 and checks its compiled SHA-256, independently of the unverified v2.0.1 first-person repair. Desktop and both mobile orientations must pass before any lobby integration. The known FPV issue remains on this baseline; no new resort is promoted automatically. Once the v2.0.1 repair and geographic data are verified, rebuild all four with the same revised engine and repeat shared HTTP cache tests.

The long-term goal is to represent the linked Valloire–Valmeinier area, which needs additional sectors or a larger tiled terrain design; do not extend a single 5 m grid beyond existing size and performance gates.
